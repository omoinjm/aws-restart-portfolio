# AWS SimuLearn: [Core Security Concepts](https://skillbuilder.aws/learn/3KYWQBTSTV/aws-simulearn-core-security-concepts/Q29T2DWZPK?parentId=1UQVR262ZB)

In this AWS SimuLearn project, I locked down a stock exchange's security by designing a role-based access system that restricts support engineers to only what they absolutely need—nothing more. I nailed down the requirements by talking through the scenario with an AI customer, then built and tested the solution in a live AWS console. End result: real-world chops in implementing least-privilege access controls and securing sensitive environments without getting in the way of the people who need to do their jobs.
