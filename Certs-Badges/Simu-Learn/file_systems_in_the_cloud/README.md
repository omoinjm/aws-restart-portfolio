**SimuLearn: Pet Modeling Agency File Sharing Solution**

In this hands-on AWS SimuLearn project, I designed and built a cloud file-sharing solution for a pet agency, eliminating their need for physical storage. I strengthened my technical skills by deploying the architecture in a live AWS console and honed my communication abilities by consulting with an AI-generated customer to nail down the requirements. The experience sharpened my ability to translate a real-world business problem into a practical, scalable cloud solution.
