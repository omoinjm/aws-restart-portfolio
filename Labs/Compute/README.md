# Lab 2: Launching an EC2 Instance

## Objective
To launch and connect to an Amazon EC2 instance using best practices.

## AWS Services Used
- Amazon EC2
- Amazon VPC
- Security Groups
- Key Pairs

## Steps Performed
1. Selected an Amazon Linux AMI
2. Chose an appropriate instance type
3. Configured network settings
4. Created and attached a security group
5. Connected to the instance using SSH

## Outcome
- EC2 instance launched successfully
- Secure access configured

## Key Learnings
- EC2 instance lifecycle
- Security group rules
- Importance of least-privilege access
